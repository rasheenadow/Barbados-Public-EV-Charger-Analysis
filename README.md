# Barbados-Public-EV-Charger-Analysis

## Project TItle & Description
**Project Title:** Barbados Public EV Charger Analysis
**Description:** A data science capstone project analysing usage, demand, and spatial patterns of Barbados’ 57 public EV charger stations to recommend optimal locations for charger expansion, upgrades, or new installations (to support improve user accessibility and national electrification goals). 

**Data Utilised:** The following types of backend operator ChargeLab app data is utilised: session logs, charger types, socket usage, peak times, and energy delivered (kWh) and spatial datasets, along with parish-level EV customer distribution (*from the company that owns the all of the public charging infrastructure). 

## File Organization
- 'raw_data/' – Original datasets (CSV, TXT, GIS layers, or other unmodified files).
- 'processed_data/' – Cleaned and transformed datasets ready for analysis.
- 'scripts/' – Python and/or R scripts used for data cleaning, spatial analysis, and modeling.
- 'metadata/' – Data dictionaries, variable descriptions, and data provenance.
- 'outputs/- – Generated figures, tables, maps, and summary results.
  
## Requirements
**Software:** R (4.0+), Python (3.8+)
**R packages:** tidyverse, readr, dplyr
**Python packages:** pandas, numpy, matplotlib, geopandas
